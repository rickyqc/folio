# Code of conduct

Folio follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers (especially people who've never used GitHub), and keep criticism about the work, not the person.

If someone isn't, report it privately to the maintainer through [GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam), or by contacting the repository owner directly. Reports are kept confidential.
