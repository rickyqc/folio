# Folio

Your links. Your page. Your domain. Free forever.

Folio is an open-source link-in-bio page you own outright: edit one config file, push to GitHub, and get a fast page on your own domain.

> Work in progress. See [docs/VISION.md](docs/VISION.md) for the spec.

## Develop

```sh
npm install
npm run dev     # local preview
npm run ci      # lint, format, typecheck, test, build, page budget
```
