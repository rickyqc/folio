# Security

Folio builds static files and runs no server, so most security issues would be in the build tools or in what the published page loads.

**Please don't report security problems in public issues.** Use GitHub's private reporting instead: go to the [Security tab](https://github.com/rickyqc/folio/security) and click **Report a vulnerability**. You'll get a reply within a week.

Only the latest release gets security fixes.
